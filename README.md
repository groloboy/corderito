# El corderito perdido

Un pequeño juego en siluetas inspirado en la parábola de la oveja perdida (Lucas 15).
Guía al corderito por la colina hasta el Buen Pastor: salta las zarzas de espinas,
recoge lucecitas y no te quedes quieto mucho tiempo, porque la oscuridad acecha.

## Cómo jugar
- Mantén presionada la pantalla (o la flecha →) para avanzar.
- Pulsa «Saltar» (o Espacio) para saltar; otra vez en el aire para un doble salto.
- Si te quedas en la oscuridad, intenta avanzar y luego pulsa «Orar».

Es un solo archivo HTML, sin dependencias: abre `index.html` en el navegador.
